A Fox's Tale Privacy Policy

Effective date: 2026-01-05

1. Data Collection

This game does not collect, process, transmit, or store any personal data. No information is sent from the game to external servers or third parties.

2. Local Device Storage

The game stores game progress locally on the user’s device only. This data never leaves the device and is not shared with the developer or any third party. The game requests permission to store this data on first launch. If permission is denied, the game exits and deletes any saved progress.

3. Ads and Analytics

This game does not display advertisements. This game does not use analytics, crash reporting, tracking technologies, or any third-party SDKs that collect user data.

4. Third-Party Assets

All graphics, music, sound effects, and other assets included in this game are either original or used under appropriate licenses. These assets do not collect or transmit any user data.

5. Children’s Privacy

This game complies with applicable privacy regulations, including COPPA and GDPR. No personal information is collected from children or any other users.
